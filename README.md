# Practical Exercise 5 — Weeknight Table

A beginner-friendly, multi-page recipe website for the ITE 10 HTML Foundations activity. It contains a homepage and three separate recipe pages, semantic landmarks, linked navigation, accessible image descriptions, lists, a comparison table, a local feedback form demo, and a locally stored audio cue. Per the HTML-only direction, the pages use the browser's default presentation rather than a designed stylesheet.

## Run locally
Open `index.html` in a browser, or serve this folder with Python (`python -m http.server 8000`) and visit `http://localhost:8000`. All image/audio paths are relative. No build tools or JavaScript are required.

## Contents
- `index.html` — recipe homepage, comparison table, audio player, feedback form
- `recipes/` — Lemon Herb Pasta, Crispy Chickpea Bowls, and Skillet Shakshuka
- `images/` — local photos and source/license notes
- `media/timer-chime.wav` — original two-note audio cue
- `LEARNING_NOTES.md` — plain-language HTML, assets, lists, forms, and audio walkthrough

## Accessibility choices
A skip link, semantic page landmarks, ordered and unordered lists, descriptive image alt text, native keyboard-operable links and controls, explicit form labels and fieldset/legend, table caption and header scopes, an audio transcript, and headings in logical order are provided. No designed stylesheet is used; native browser focus indicators remain available. Recipe notes supplement—rather than replace—the steps.
